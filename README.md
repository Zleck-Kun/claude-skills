# claude-skills

Personal Claude Code skills, in `.claude/skills/`.

- `karpathy-guidelines` — from [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) (MIT)
- Everything else — from [mattpocock/skills](https://github.com/mattpocock/skills) (MIT), snapshot of commit 5863806

## Use

- **Cloud sessions:** attach this repo to the session; skills load automatically.
- **Locally, all projects:** `cp -r .claude/skills/* ~/.claude/skills/`
- **One project:** copy the folders you want into that project's `.claude/skills/`.
